# 命令行待办事项应用（Todo CLI）

## 项目目标

为个人用户提供一个零依赖的命令行待办事项管理工具，数据本地持久化，支持脚本化调用。

## 功能需求

- 用户可以添加待办事项，自动分配唯一 ID 并记录创建时间
- 用户可以列出全部待办事项，并区分已完成 / 未完成状态
- 用户可以按 ID 将事项标记为完成
- 用户可以按 ID 删除事项
- 用户可以查看统计信息（总数、已完成数、完成率）
- 数据以 JSON 文件保存在本地，进程退出后不丢失
- 非法输入（不存在的 ID、空标题）要给出友好提示，不崩溃

## 约束

- Python 3.9+，仅使用标准库
- 提供自动化测试，覆盖增删改查与持久化
