# 需求规格说明书：命令行待办事项应用（Todo CLI）

> 由 RequirementAgent 基于原始需求自动整理，供 DesignAgent / CodingAgent 使用。

## 1. 项目目标

构建一个零第三方依赖的命令行应用，功能聚焦、可离线运行、可自动化验证。

## 2. 功能需求

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| FR-01 | 用户可以添加待办事项，自动分配唯一 ID 并记录创建时间 | P0 |
| FR-02 | 用户可以列出全部待办事项，并区分已完成 / 未完成状态 | P0 |
| FR-03 | 用户可以按 ID 将事项标记为完成 | P0 |
| FR-04 | 用户可以按 ID 删除事项 | P1 |
| FR-05 | 用户可以查看统计信息（总数、已完成数、完成率） | P1 |
| FR-06 | 数据以 JSON 文件保存在本地，进程退出后不丢失 | P1 |
| FR-07 | 非法输入（不存在的 ID、空标题）要给出友好提示，不崩溃 | P1 |
